# Kinoura
**Kinoura** es una plataforma centralizada para buscar funciones, comparar precios y encontrar las mejores promociones dentro de los distintos cines de tu ciudad.

**Mejoras para la pre-entrega 3**
Se mantuvo el layout general de la página web pero se pasó de `display: inline-block` a `display: flexbox` y se usaron las propiedades de las cajas flexibles para centrar elementos y acomodarlos según la necesidad. Se incorporó el uso de **Material Icons**, se mejoró la **barra de navegación** y se hizo una re-estructuración de la página **Nosotros**.

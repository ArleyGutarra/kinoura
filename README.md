# Kinoura
**Kinoura** es una plataforma centralizada para buscar funciones, comparar precios y encontrar las mejores promociones dentro de los distintos cines de tu ciudad.


**UPDATES Y UPGRADES DE LA PRE-ENTREGA 5**

* Se agregó la Navbar usando **Bootstrap** en todas las páginas
* Se agregó el **Carrusel de Bootstrap** para el banner de Home. 
* En la página Nosotros, se añadió una sección de Contáctanos utilizando **Forms de Bootstrap**
* Se añadieron **pseudoclases** para interactividad de la Navbar, de las Tabs en Películas y del botón de envío en el form de Contáctanos.
